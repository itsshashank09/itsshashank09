# Hi, I'm Shashank

I'm a junior web developer. I build web apps with React, JavaScript, PHP and Python, and I'm learning how to make them easier to run, test and maintain.

My projects cover a few different parts of web development: a QR-based print-shop workflow, a freelance marketplace, a service website and a small task manager.

## Selected projects

### [PrintWithQR](https://github.com/itsshashank09/PrintWithQR)

Customers scan a shop's QR code, upload documents and choose print settings. The shop manages the orders from a dashboard. This is my most involved project, with Supabase data and file storage, realtime order updates, serverless API handlers and Razorpay subscription payments.

**React · JavaScript · Vite · Supabase · Razorpay · Vercel**  
[Website](https://www.printwithqr.in/) · [Architecture](https://github.com/itsshashank09/PrintWithQR/blob/main/docs/architecture.md)

### [NeXLace](https://github.com/itsshashank09/NeXLace)

A freelance marketplace prototype with developer profiles, job applications, invitations, messaging and notifications. I used it to work through PHP sessions, database queries and features that connect several screens.

**PHP · MySQL · JavaScript · HTML/CSS · Node.js**  
[Project notes](https://github.com/itsshashank09/NeXLace/blob/main/docs/architecture.md)
